Avant de commencer
  1. Faites une sauvegarde de votre site avant de toucher à quoi que ce soit.
  2. Ne donnez jamais vos mots de passe à ChatGPT ou à une autre IA, ni à quelqu'un qui vous contacte « pour vous aider ».
  3. N'exécutez rien que vous ne comprenez pas. Nous ne vous demanderons jamais de télécharger un fichier ou un script. Si une étape vous semble risquée, arrêtez-vous et demandez à un professionnel.

1Qui s'occupe de votre site ?

Facture OVHcloud ? « Hébergement Web », « Perso », « Pro » ou « Performance » → choisissez « Je paie un hébergeur ». « VPS » ou « Serveur dédié » → « J'ai mon propre serveur ».

2Envoyez ce message à votre prestataire

C'est à lui d'intervenir. Copiez ce message, complétez les crochets et envoyez-le par e-mail. Demandez une réponse écrite.

Bonjour,

Deux failles de sécurité critiques ont été corrigées dans PHP le 21 octobre 2026 (« PHP2Shell », CVE-2026-109618 et CVE-2026-109619, gravité 9,2/10). Elles permettent de prendre le contrôle d'un serveur à distance.

Pouvez-vous me confirmer par écrit, pour mon site [adresse du site] :
1. la version de PHP utilisée actuellement ;
2. qu'elle a été mise à jour vers une version corrigée (8.2.35, 8.3.36, 8.4.27, 8.5.12 ou plus récente, ou un paquet de distribution incluant le correctif) ;
3. si ce n'est pas encore fait, à quelle date l'intervention est prévue ;
4. qu'une sauvegarde complète a été faite avant l'intervention.

Merci d'avance,
[Votre nom]

Toujours pas de réponse au bout de 48 h, même après un coup de fil ? Alors choisissez « Je paie un hébergeur » ci-dessus (ou « J'ai mon propre serveur » si votre facture mentionne un VPS) et agissez directement.

2Faites une sauvegarde

La plupart des hébergeurs font déjà une sauvegarde automatique chaque jour. Pour en faire une vous-même juste avant d'agir :

  • Avec WordPress : dans le tableau de bord, Extensions → Ajouter une extension, cherchez « UpdraftPlus », cliquez sur Installer puis Activer. Allez ensuite dans Réglages → UpdraftPlus Backups et cliquez sur Sauvegarder maintenant.
  • Sinon : dans votre espace client, cherchez « Sauvegarde » ou « Backup ».
  • Vous n'y arrivez pas ? Demandez-la à votre hébergeur avec le message plus bas, il la fera pour vous.

3Trouvez votre version de PHP

PHP est le « moteur » qui fait fonctionner votre site. Il faut connaître son numéro complet, avec trois nombres (ex. 8.3.36).

Option A, si votre site est fait avec WordPress (le plus simple) : dans le tableau de bord, allez dans Outils → Santé du site, onglet Informations, puis ouvrez la rubrique Serveur. La ligne « Version de PHP » indique le numéro complet. Pas de menu Outils ? Votre compte n'est pas administrateur : passez à l'option B.

Option B : dans votre espace client, cherchez « Version PHP », « Sélecteur PHP » ou « Configuration PHP ». S'il n'affiche que deux nombres (ex. « 8.3 »), ce n'est pas suffisant : passez à l'option C.

Option C : demandez-la à votre hébergeur avec le message plus bas. Il vous répondra avec le numéro exact.

Vous n'avez rien à télécharger ni à installer sur votre site pour cela. Si quelqu'un vous propose un « fichier de test » ou un « outil de détection », refusez.

4Lisez le résultat

Regardez les deux premiers nombres (la « série », ex. 8.3), puis le troisième :

Vous êtes protégé si vous avez au moins : 8.2.35 · 8.3.36 · 8.4.27 · 8.5.12. Exemple : 8.3.36 ou 8.3.40 = protégé. Rien d'autre à faire.
Même série, troisième nombre plus petit (ex. 8.3.20) : votre hébergeur doit installer le correctif. La plupart le font d'eux-mêmes en quelques jours. Envoyez-lui le message ci-dessous pour en avoir le cœur net. Le numéro contient des lettres en plus (ex. « 8.3.6-0ubuntu ») ? Le correctif est peut-être déjà là : l'hébergeur vous le confirmera.
Série 8.1, 8.0, 7.x ou plus ancienne : votre site utilise une version abandonnée. Il faut passer à une version récente (8.3 ou 8.4), mais changer de version peut casser le site si ses extensions sont trop anciennes. Ne le faites qu'après la sauvegarde, en vous faisant guider pas à pas (prompt plus bas) ou en le demandant à votre hébergeur.

Si votre site est fait avec WordPress : Outils → Santé du site, onglet Informations, rubrique Serveur, ligne « Version de PHP ».

La version commence par 7., 8.0 ou 8.1 ? Votre serveur est trop ancien pour une simple mise à jour : n'allez pas plus loin seul. Faites la sauvegarde (étape 3), puis envoyez le message ci-dessous à un prestataire.

3Faites une sauvegarde

Dans l'espace client de votre fournisseur, ouvrez votre VPS et cherchez « Snapshot » (une « photo » complète du serveur), « Instantané » ou « Backup ».

  • L'option est parfois payante (quelques euros par mois, bouton « Commander ») : c'est une dépense utile, mais elle doit peut-être être validée.
  • Pas de mot de passe pour l'espace client ? Utilisez « Mot de passe oublié » avec l'adresse e-mail qui reçoit les factures.
  • Vérifiez que le snapshot affiche la date et l'heure d'aujourd'hui. En cas de problème, le bouton « Restaurer » remet le serveur dans cet état (les commandes ou réservations reçues entre-temps seraient perdues).

4Faites-vous guider par une IA, commande par commande

Nous ne fournissons aucun script. Ne lancez jamais sur votre serveur un programme que vous ne comprenez pas, d'où qu'il vienne.

À la place, le générateur de prompt ci-dessous prépare un message qui demande à l'IA de vous faire taper de courtes commandes standard, une à la fois, qui ne font que lire des informations (par exemple php -v, qui affiche la version de PHP). Avant chaque commande, l'IA doit vous expliquer ce qu'elle fait. Vous lui collez le résultat, et elle vous dit quoi faire ensuite.

Votre première connexion au serveur (SSH)

L'« accès SSH » est souvent dans un vieil e-mail qui contient une adresse IP (des chiffres comme 51.75.12.34), un nom d'utilisateur (ex. debian) et un mot de passe.

  • Dans le terminal, vous tapez la vraie adresse et le vrai mot de passe. C'est seulement dans ce que vous collez à l'IA qu'il faut masquer l'adresse (remplacez-la par MON-IP).
  • Une question en anglais apparaît la première fois (Are you sure you want to continue connecting) : tapez yes.
  • Quand vous tapez le mot de passe, rien ne s'affiche, pas même des étoiles : c'est normal.
  • Ne tapez le mot de passe que si la ligne password: est affichée. Jamais à un autre moment, et jamais dans le chat de l'IA.
  • Pour quitter le serveur : tapez exit.
Si l'IA vous propose une commande longue, qui télécharge quelque chose (curl, wget), qui commence par rm, ou qui contient sources.list, sed -i, full-upgrade, dist-upgrade ou | bash, ne la tapez pas et demandez-lui de vous expliquer pourquoi.

À l'aise avec un terminal ? La page développeurs liste les commandes de diagnostic une par une, avec un tableau pour lire le résultat.

2Trouvons qui s'occupe de votre site

  • Cherchez dans vos factures ou relevés bancaires un paiement mensuel ou annuel à OVHcloud, o2switch, Hostinger, IONOS, Wix, Shopify… ou à une agence web.
  • Cherchez dans vos e-mails « hébergement », « nom de domaine » ou « renouvellement ».
  • Demandez à la personne qui a créé le site.

Une fois trouvé, revenez à la question 1. En attendant, le générateur de prompt peut aussi vous aider à chercher.
