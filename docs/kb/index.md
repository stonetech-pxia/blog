# StoneTech Blog — Knowledge Base

## Global Info

- Project type: Static personal technical blog (web site)
- Primary language(s): TypeScript / JavaScript (build-time only); site content authored in Markdown
- Key technologies / frameworks: Astro 6 static site generator, Content Collections API, MDX, Sharp image processing, Giscus (GitHub Discussions comments), deployed on Vercel
- Content language: French (published articles, page copy, navigation labels, comment widget)
- Purpose (one sentence): A statically generated personal blog where the author publishes French-language articles about coding agents and developer tooling, with per-article comments, an RSS feed, and social/SEO metadata.
