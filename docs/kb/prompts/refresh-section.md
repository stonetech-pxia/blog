# Refresh Section

Use this prompt to re-validate one existing knowledge base section against the current state of the project.

Task:

- Read the target section file and `kb.config.md`.
- Re-check every claim in the section against current project behavior.
- Update anything that has changed; move anything now uncertain to `open-questions.md`.
- Record the review in `logs/maintenance-log.md` with today's date, the section name, and the outcome (unchanged, updated, or superseded).
