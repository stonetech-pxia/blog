# Compile Architecture Page

Use this prompt to update `architecture.md`.

Task:

- Read `kb.config.md` and the `features/` pages before writing.
- Describe the system's major responsibilities and how they interact: what triggers what, what depends on what, and what data or control flows between them.
- Name responsibilities by role (for example: "the scheduling responsibility", "the notification responsibility"), never by file, folder, module, or code identifier.
- Link to the `features/` pages each responsibility supports.
- Note anything unclear in `open-questions.md` rather than guessing.
