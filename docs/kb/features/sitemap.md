# Sitemap

## Overview

A search-engine sitemap is generated automatically at build time and served at `/sitemap-index.xml`.

## Observable behavior

- Reachable at `/sitemap-index.xml` (a sitemap index that references the generated URL sitemap).
- Enumerates the site's pages so search engines can discover and crawl them.
- Advertised in every page's head via a sitemap link.
- Generated by the site's sitemap integration during the production build; no manual maintenance is required.

## Constraints & notes

- The URLs in the sitemap are absolute and depend on the deployment site URL being set correctly (see [Configuration](../configuration.md)).
- The sitemap only reflects pages that exist at build time; it is regenerated on each build.
