# Features

Every feature of StoneTech Blog gets its own page here, detailed to the smallest observable behavior.

| Feature | Description | File |
| --- | --- | --- |
| Landing page | The site home page: branded welcome and blog introduction | `landing-page.md` |
| Blog post listing | Grid index of all published articles, newest first | `blog-post-listing.md` |
| Blog post page | Full rendered article with hero image, dates, and comments | `blog-post-page.md` |
| About page | Standalone author-introduction page | `about-page.md` |
| Article comments | Per-article comment threads backed by GitHub Discussions | `article-comments.md` |
| RSS feed | Machine-readable feed of all articles | `rss-feed.md` |
| Sitemap | Auto-generated search-engine sitemap | `sitemap.md` |
| Social & SEO metadata | Per-page canonical URL, Open Graph, and Twitter card tags | `social-seo-metadata.md` |
| Site navigation & chrome | Site-wide header navigation and footer with social links | `navigation-and-chrome.md` |
| Typography & branding | Custom accessible font and site brand identity | `typography-and-branding.md` |

Add a row and a page for every feature discovered during analysis.
